# 数学公式粘贴

把复制来的数学公式粘进思源，直接变成思源公式；从思源复制出去，还原成带 `$` 的 Markdown。

## 粘贴进来

| 复制来源的写法                           | 思源里得到             |
| --------------------------------- | ----------------- |
| `\(x=1\)`、`$x=1$`                 | 行内公式 `$x=1$`      |
| `\[ x=1 \]`、`$$ x=1 $$`           | 公式块 `$$`，不管写在哪都算块 |
| `\begin{align} … \end{align}` 等环境 | 公式块，环境名保留         |

## 复制出去

`Ctrl+C` 和菜单里的「复制富文本」不会把公式转成 Markdown，要从下面三个入口复制：

**入口**（三选一）：

- 选中内容 → 右键 → 菜单末尾的「插件」子菜单 → 「复制为 Markdown（含公式）」
- 点块图标 → 「复制为 Markdown（含公式）」（块里有公式时才出现）
- 命令面板搜「复制为 Markdown（含公式）」；或去「设置 → 快捷键」自己绑

**效果**

| 思源里             | 复制出去           |
| --------------- | -------------- |
| 行内公式            | `$…$`          |
| 公式块             | `$$` 块         |
| 加粗的公式           | `**$…$**`      |
| 列表、标题、引用、表格、代码块 | 标准 Markdown 结构 |
| 选区里没有公式         | 不插手，走思源原生复制    |

## 开发

```bash
npm run dev        # 监听构建，产物直接进工作区（.env 里配 SIYUAN_WORKSPACE）
npm run build      # 一次性构建到 dist/
npm test           # 103 个用例
npm run typecheck  # 类型检查
```
